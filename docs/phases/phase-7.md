## ทดสอบแล้ว

- **seed ชุดใหญ่ (20 ร้าน):** รันจาก DB ว่าง → ไม่มีการจองของสมชาย/มะลิถูกข้าม · ค่าเฉลี่ย/จำนวนรีวิว 7 ร้านแรกยังตรงดีไซน์ · `requests.http` 43 request ได้ผลตรง "คาดหวัง:" ทุกตัว (รันครั้งเดียวบนข้อมูลที่เพิ่ง seed)

- **Clone test:** คัดลอกเฉพาะไฟล์ที่ git จะเก็บ (159 ไฟล์) ไปโฟลเดอร์ใหม่ → `docker compose -p <ชื่อใหม่> up --build` → seed เอง · 7 ร้านเรียงถูก · รูปขึ้น · login สมชายเห็นการจองครบทุกแท็บ
- `requests.http` ทุก request ได้ผลตรงบรรทัด "คาดหวัง:" บน stack ใน Docker
- login / logout ใน Docker · image api 57.8MB · web 308MB
